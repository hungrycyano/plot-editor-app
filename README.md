# plot-editor-app

小説のプロット（骨組み）を作るツール **plot-editor** の公開用リポジトリです。
GitHub Pages でアプリを公開するためのファイルだけを置いています。

- アプリ：https://hungrycyano.github.io/plot-editor-app/
- 使い方・mdファイルの書式：元のリポジトリ [hungrycyano/plot-editor](https://github.com/hungrycyano/plot-editor) の README を参照

## 更新のしかた
アプリは元のリポジトリ `plot-editor` で開発します。変更したら、次のファイルをこのリポジトリへコピーしてください。

```
index.html  manifest.webmanifest  sw.js  css/  js/  lib/  icons/
```

`sw.js` の `VERSION` を変えておくと、利用者の端末で新しい版に切り替わります。
